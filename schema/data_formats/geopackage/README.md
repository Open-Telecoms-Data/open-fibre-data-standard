`network-schema.gpkg` is generated by the `manage.py` script when the `pre-commit` command is run. Do not edit this file directly. Instead, edit the source `network-schema.json` file and run `pre-commit` to regenerate the GeoPackage.

`examples/geopackage/network.gpkg` is also generated by `pre-commit`, from `examples/json/network-package.json`. See `populate_gpkg.py`.
